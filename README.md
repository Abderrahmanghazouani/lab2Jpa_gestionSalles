# lab2Jpa_gestionSalles
Application Java 21 (Maven) qui utilise JPA et Hibernate avec une base H2 en mémoire pour gérer des salles et leurs utilisateurs. Chaque utilisateur est associé à une salle.
Le projet est organisé en couches (entités, DAO, service) et testé avec JUnit 4 : création de salles, ajout d'utilisateurs et recherche des utilisateurs par salle.
